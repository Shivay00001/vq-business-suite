Usage metering — FAQs

What is usage metering for?

If you sell API access or metered tools, log each client's consumed units against their quota, watch the 80% near-quota band, and estimate overage bills automatically.

यूसेज मीटरींग क्या है?

अगर आप API या टूल की यूसेज बेचते हैं, तो हर क्लाइंट की खपत कोटा के मुकाबले दर्ज करें और ओवरेज बिल का अनुमान पाएं।

When is a client flagged near quota?

At 80% of quota the status flips to "near quota"; at 100% "at quota"; above 100% "over quota" with an overage amount.

Is usage data uploaded anywhere?

No. Client quotas and usage logs stay in the on-device vault in your browser.
