FAQs — अक्सर पूछे जाने वाले सवाल

Git me last commit kaise undo karein?

Push nahi kiya to "git reset --soft HEAD~1" (changes staged rehte hain) ya "--mixed". Push kar diya to "git revert HEAD" — ye naya undo-commit banata hai, history rewrite nahi karta.

Git stash kya hota hai?

Stash adhoora kaam temporarily side me rakh deta hai taaki working tree clean mile — "git stash push -m wip", phir "git stash pop" se wapas layein.

git rebase vs git merge me kya antar hai?

Merge branch structure preserve karta hai (merge commit ke saath); rebase commits ko target ke upar replay karke linear history banata hai. Sirf local/private branches par rebase karein — pushed shared history kabhi rewrite na karein.

Galti se delete hui file ya commit kaise wapas layein?

"git reflog" batata hai HEAD kahan-kahan gaya — khoya commit hash mil jayega, phir "git reset --hard <hash>" ya "git checkout <hash> -- <file>" se restore karein.
