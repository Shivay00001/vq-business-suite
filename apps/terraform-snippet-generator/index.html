        Terraform HCL snippet kaise likhein?
        
    Resource block is format me hota hai: resource "aws_instance" "web" { ami = ... instance_type = "t3.micro" }. Yahan preset chunein, fields bharein — generator resource ke saath variables block bhi likhega.
    
      
    
      
    
        Terraform variables kya hote hain?
        
    Variables se wahi config alag values ke saath reuse hoti hai (dev vs prod). "variable" block se declare karein, var.name se reference karein, -var flags ya .tfvars file se override karein.
    
      
    
      
    
        Terraform apply se pehle kya check karein?
        
    Hamesha pehle "terraform plan" chalakar diff padhein. Production me state remote (S3 + DynamoDB lock) me rakhein.
    
      
    
      
    
        RDS password Terraform me kaise secure rakhein?
        
    Variable ko sensitive = true mark karein, asli value git-ignored .tfvars file ya AWS Secrets Manager me rakhein — passwords kabhi git me commit na karein.
