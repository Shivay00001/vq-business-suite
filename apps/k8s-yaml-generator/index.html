FAQs — अक्सर पूछे जाने वाले सवाल

      

        Kubernetes Deployment YAML kaise likhein?
        
apiVersion: apps/v1, kind: Deployment, metadata.name, pod template se match karta selector, replicas, aur container spec (image, ports, env, resources) chahiye hota hai. Ye generator Deployment ke saath matching Service bhi banata hai.

      

      

        ClusterIP vs NodePort vs LoadBalancer me kya antar hai?
        
ClusterIP app ko sirf cluster ke andar expose karta hai. NodePort har node par ek port kholta hai. LoadBalancer (AWS/GCP/Azure par) Service ke saamne cloud load balancer provision karta hai.

      

      

        Resource requests aur limits kya hote hain?
        
Requests scheduler ko batate hain ki pod ko kitni CPU/memory chahiye; limits cap lagate hain ki wo usse zyada use na kare. Dono set karein taaki ek noisy pod poore node ko slow na kare.

      

      

        Generated YAML ko kaise apply karein?
        
File ko app.yaml naam dekar "kubectl apply -f app.yaml" chalaiye, phir "kubectl rollout status deployment/<name>" se rollout check karein.
