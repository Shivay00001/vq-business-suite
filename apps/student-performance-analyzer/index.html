Student performance analyzer — FAQs

How does the trend analysis work?

With marks from 2+ exams it compares the first and latest exam percentages: a rise over 2 points is improving, a fall over 2 points is declining, otherwise stable.

मज़बूत और कमज़ोर विषय कैसे पता चलता है?

हर विषय का सभी परीक्षाओं का औसत प्रतिशत निकाला जाता है — सबसे ऊँचा औसत मज़बूत विषय, सबसे नीचा कमज़ोर विषय। उसी के हिसाब से पढ़ाई की प्राथमिकता तय करें।

Where does it get marks data from?

It reads the same browser vault used by the Marks Entry Tool, so no double entry. Data never leaves your device.

Is the topper list official?

No — it is an average of entered marks, not a board result. Verify before publishing any merit list.
