# Tender Submission Checklist

Two-bid system document checklist for Indian tenders: **technical bid (Envelope 1)**
+ **financial bid (Envelope 2)**, with per-section and overall completion %,
ready-to-submit flag, and a pending-documents list.

## Default documents

- **Technical:** EMD / Bid Securing Declaration, tender fee receipt, GST, PAN,
  incorporation proof, Udyam/NSIC, 3-year audited financials, CA turnover
  certificate, 3-year ITRs, experience/completion certificates, ongoing works
  list, non-blacklisting affidavit, power of attorney, NIT declaration forms,
  DSC, solvency certificate.
- **Financial:** BOQ/price schedule (figures + words), price declaration,
  GST treatment per NIT, unconditional offer, validity period declaration.

Add NIT-specific items as custom documents (dedupe-checked, removable).

## Notes

- Common-documents starting point — the NIT and corrigenda are authoritative.
- One missing technical document can disqualify the whole bid.
