    FAQs — अक्सर पूछे जाने वाले सवाल
    
      
    
        Dockerfile kaise banaye?
        
    Base image chunein (jaise node:20-alpine), WORKDIR set karein, code COPY karein, RUN me install/build steps likhein, EXPOSE me port, aur ant me CMD/ENTRYPOINT. Ye generator ye sab assemble karke lint hints ke saath deta hai.
    
      
    
      
    
        Dockerfile me "latest" tag kyon avoid karna chahiye?
        
    "latest" tag samay ke saath badalta rehta hai — aaj ka build kal toot sakta hai. Hamesha explicit version pin karein, jaise node:20-alpine, taaki builds reproducible rahein.
    
      
    
      
    
        Multi-stage build kya hota hai?
        
    Ek stage me compile/install hota hai, doosri slim stage me sirf built artefacts copy hote hain. Final image chhoti rehti hai aur usme compiler ya devDependencies nahi aate.
    
      
    
      
    
        .dockerignore kyon zaroori hai?
        
    COPY . . poora build context bhejta hai. Bina .dockerignore ke node_modules, .git aur .env image me chale jaate hain — build slow hota hai aur secrets leak ho sakte hain.
