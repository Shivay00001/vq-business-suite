FAQs — अक्सर पूछे जाने वाले सवाल

      

        docker-compose.yml kaise banaye?
        
"services:" ke neeche har container likhein — image, ports, volumes, environment aur depends_on ke saath. Ye generator aapke liye YAML banata hai; phir "docker compose up -d" chalaiye.

      

      

        docker compose aur docker-compose me kya antar hai?
        
"docker compose" (space) naya Compose v2 plugin hai; "docker-compose" (hyphen) purana v1 tool tha. Nayi files me "version:" key obsolete hai — ye generator use nahi likhta.

      

      

        depends_on kya karta hai?
        
Ye startup order control karta hai — jaise web service depends_on db, to database container pehle start hoga. "Ready hone tak wait" ke liye healthcheck ke saath combine karein.

      

      

        Compose file me passwords kaise secure rakhein?
        
Passwords commit ki hui YAML me na likhein. Git-ignored .env file ke saath env_file use karein ya ${DB_PASSWORD} jaise references.
