# Vendor Collusion Risk Tool — `vendor-collusion-risk-tool`

10-indicator checklist (same-address vendors, round-amount invoices,
single-bidder pattern, sequential invoice numbers, split orders, cover
bidding…) with weights → collusion-risk score % + Low/Moderate/High band
+ the investigative check for each ticked pattern. Assessments savable to
on-device vault (max 25).

## Free limits
20 assessments/day (metered). Vault saves capped at 25.

## Honest limitation
Diagnostic, not accusatory: an indicator is a pattern to investigate,
never proof of collusion. Not legal advice — confirm with your auditor.
