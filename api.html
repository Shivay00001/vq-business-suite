Enterprise API

Documentation preview — the API does not exist yet. This page documents the planned Enterprise tier so client code can be written against matching shapes from day one. Nothing here is callable today.

Base URL (planned)

https://api.visionquantech.com/v1 — HTTPS only, JSON in and out.

Authentication

API keys issued per workspace, sent as a Bearer token. Keys will be creatable and revocable from the (future) dashboard.

Endpoints by tool family

POST /v1/gst/interest

Interest on delayed GST payment.

{
  "principal": 50000,
  "from": "2026-07-21",
  "to": "2026-09-26",
  "rate_pa": 18
}
POST /v1/loans/emi

EMI, total interest and amortisation schedule.

{
  "principal": 1000000,
  "annual_rate": 9.5,
  "tenure_months": 60
}
POST /v1/hr/salary-breakup

CTC → in-hand breakup (PF, ESI, professional tax estimates).

{
  "ctc_annual": 600000,
  "state": "MH"
}
POST /v1/analytics/profit-loss

Profit & loss from revenue/expense line items.

{
  "period": "2026-09",
  "revenue": [{"label": "Sales", "amount": 250000}],
  "expenses": [{"label": "Rent", "amount": 40000}]
}
POST /v1/invoicing/invoices

Create a GST invoice; returns a renderable document object.

{
  "seller": {"name": "Acme Traders", "gstin": "27ABCDE1234F1Z5"},
  "items": [{"desc": "Widget", "qty": 10, "rate": 100, "gst_rate": 18}]
}
GET /v1/vault/documents  ·  POST /v1/vault/documents

List / store encrypted documents (server-side E2E model planned).

API pricing (planned)

Enterprise API is custom annual pricing based on volume. The client-side suite stays free; only server API usage is metered.

Design notes for integrators

  • All money fields are in paise (integers) to avoid float errors.
  • Dates are ISO 8601 (YYYY-MM-DD).
  • Errors use {"error": {"code": "...", "message": "..."}}.
  • The calculation logic mirrors the client-side tools exactly — same formulas, same rounding.
