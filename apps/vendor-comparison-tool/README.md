# Vendor Comparison Tool
Cluster: procurement-vendor (Team I, batch 4).
Side-by-side vendor quote comparison on price, lead time, warranty and rating. Criteria normalised 0–1 across the compared set (lower better for price/lead; higher better for warranty/rating), weighted by the user (must total 100), ranked 0–100. Up to 25 comparisons saved in the on-device vault.
