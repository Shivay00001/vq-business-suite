Marks entry tool — FAQs

How do I enter marks?

Fill student name, exam, subject, marks and max marks, then press Add. The tool rejects marks above the maximum and computes percentage, grade and rank automatically.

ग्रेड कैसे तय होता है?

90%+ = A+, 80%+ = A, 70%+ = B, 60%+ = C, 50%+ = D, 40%+ = E, उससे कम = F। आप अपने बोर्ड के ग्रेड स्केल से मिलान कर लें।

How are ties handled in rank?

Students with the same total share the same rank (dense ranking), so you may see two Rank 2s followed by Rank 3.

Can I correct a wrong entry?

Yes — re-enter the same student + exam + subject and the old entry is replaced.

Where is marks data stored?

Only in your browser vault. Nothing is uploaded anywhere.
