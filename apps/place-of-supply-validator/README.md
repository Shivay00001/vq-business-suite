# Place of Supply Checker — `place-of-supply-validator`

Supplier state + recipient state (+ recipient type, supply nature, scenario) →
place-of-supply state + CGST+SGST / IGST / zero-rated verdict, with the IGST
Act section cited in plain words.

## Statutory basis (verified Sep 2026), IGST Act 2017
- Sec 10(1)(a)/(b)/(c)/(e): goods — movement termination / bill-to-ship-to
  (deemed received by third person) / no movement / taken on board.
- Sec 11: imports (location of importer) / exports (outside India, zero-rated).
- Sec 12(2): services B2B → recipient location; B2C → recipient address on
  record else supplier. Sec 12(3): immovable property. Sec 12(4): restaurant.
  Sec 12(8): goods transport. Sec 12(9): passenger transport. Sec 12(10):
  on-board services. Sec 13(2): cross-border general rule.
- Sec 7/8: inter-state vs intra-state classification.

20 checks/day (metered).
