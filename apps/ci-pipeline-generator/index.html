FAQs — अक्सर पूछे जाने वाले सवाल

      

        GitHub Actions workflow YAML kaise likhein?
        
.github/workflows/ci.yml me "on:" triggers, "jobs:" aur "steps:" likhein — checkout, language setup, install, test, build. Ye generator language preset se poori file likh deta hai.

      

      

        Jenkinsfile (Declarative Pipeline) kaise likhein?
        
Declarative Jenkinsfile me "pipeline { agent any stages { stage(...) } }" structure hota hai, sh steps ke saath. Yahan Jenkins tab chunein — generator Docker push stage samet poori file likhega.

      

      

        CI me Docker image push kaise karein?
        
Registry credentials secrets me rakhein (kabhi hardcode na karein), phir build aur push karein. Generated pipeline GitHub secrets ya Jenkins "registry-creds" credential use karti hai.

      

      

        GitHub Actions free hai kya?
        
Haan — public repos ke liye generous free minutes, private repos ke liye free plan par 2,000 minutes/month.
