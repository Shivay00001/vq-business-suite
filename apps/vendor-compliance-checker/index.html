FAQs — अक्सर पूछे जाने वाले सवाल

GSTIN ka format kya hota hai?

15 characters: 2-digit state code (e.g. 27 = Maharashtra) + 10-character PAN + 1 entity code (usually 1) + letter 'Z' + 1 check digit (checksum se banta hai, typo pakadne ke liye).

Checksum fail ka matlab vendor fake hai?

Nahi — zyada-tar cases me ye typing mistake hoti hai. Check digit galat ho to pehle GSTIN dobara verify karein (invoice ya registration certificate se), phir portal par status check karein.

Kya ye tool vendor ka live GST status batata hai?

Nahi. Live status (active/cancelled/suspended) sirf gst.gov.in → Search Taxpayer par milta hai — iske liye GSTN API chahiye jo ek static offline tool me nahi ho sakta. Ye tool format-level validation + risk heuristics deta hai.

Vendor list kahan save hoti hai?

Sirf aapke browser ke local vault me (passphrase se encrypt ho sakti hai). Maximum 25 vendors; delete kabhi bhi kar sakte hain.

Risk score kaise banta hai?

Checksum fail ya format error → high/invalid; PAN/entity pattern issues ya duplicate entries → medium; sab checks pass → low (format OK). Ye heuristic hai — high flag ka matlab "portal par verify karein" hai.
