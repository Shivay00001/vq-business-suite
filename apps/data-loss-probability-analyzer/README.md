# Data Loss Probability Analyzer — `data-loss-probability-analyzer`

5-question backup-posture self-assessment (frequency, locations,
encryption, tested restores, device age) → 0–100 data-loss risk score,
Low/Moderate/High band, RPO estimate, prioritised recommendations
(3-2-1 rule guidance). Analyses savable to on-device vault (max 25).

## Free limits
20 analyses/day (metered). Vault saves capped at 25.

## Honest limitation
Estimate from the user's own answers, not an IT security audit.
Confirm with IT support/auditor.
