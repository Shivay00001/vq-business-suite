# Long-Term Data Preservation Tool

Statutory record-retention schedule for India with destruction-eligibility alerts. Periods verified via web search Sep 2026; statutes + source links shown on screen.

- **Cluster:** platform-lifecycle (Cluster N)
- **Slug:** `long-term-data-preservation-tool`
- **Files:** `index.html`, `app.js`
- **Storage:** browser vault (`batches` record), max 25, reads unmetered. **Metering:** 20 checks/day.

Verified minimums: Companies Act Sec 128(5) 8 FYs · IT Act 6 yrs from AY end (Rule 6F) · Rule 10D TP docs 8 yrs · foreign-asset escape 16 yrs · CGST Sec 36 72 months · ESI Regs Rules 32/66 5 yrs · Payment of Wages Sec 13A(2) 3 yrs · PF ~6 yrs (forum guidance, flagged as unconfirmed).

Pure API: `retentionFor`, `destroyAfter`, `status`, `addItem`, `removeItem`, `esc`.
