FAQs — अक्सर पूछे जाने वाले सवाल

Deployment se pehle kya check karna chahiye?

Code review + merge, green CI, reviewed DB migrations with rollback plan, production secrets set, version tag, changelog, aur fresh production DB backup.

Deploy ke dauraan kya monitor karein?

Pehle staging par deploy karke smoke test, phir migrations, phir rolling/blue-green deploy to prod. Kam se kam 15 minute tak health checks aur error rates dekhein.

Deploy ke baad kya verify karein?

Production par smoke tests, key user flows (login, checkout, payments), logs/metrics dashboards, backup schedules, aur stakeholders ko notification.

Rollback plan kyon zaroori hai?

Har deploy fail ho sakta hai. Likha hua rollback plan — previous image tag, migration down-steps, kaun decide karega — 2 AM panic ko 5-minute routine bana deta hai.

Kya meri checklist progress save hoti hai?

Haan — "Save progress" dabayein, ye device ke vault me store hoti hai (optional passphrase encryption ke saath). Kuch bhi browser ke bahar nahi jaata.
