Document vault — FAQs

Is the document vault really encrypted?

Yes, when you set a passphrase: entries are encrypted with AES-256-GCM (via WebCrypto) before being stored, and the key lives only in memory until you close the tab. Without a passphrase, entries are stored as plain JSON in your browser.

Where is my data stored?

Only in this browser's localStorage, under this app's private namespace. Nothing is uploaded to any server. Clearing browser data deletes your vault — use the JSON export as a backup.

डॉक्यूमेंट वॉल्ट कैसे काम करता है?

पासफ्रेज़ सेट करें, GST/टैक्स, इनवॉयस, HR या कानूनी दस्तावेज़ जोड़ें, समाप्ति तिथि डालें — वॉल्ट आपको समय पर याद दिलाएगा। सारा डेटा आपके ब्राउज़र में ही रहता है।

What is the file attachment limit?

About 4 MB per attachment. Compress large scans first — browsers allow only ~5 MB of local storage per site.

How many documents are free?

25 documents on the free plan. Exporting your vault to JSON for backup is always free and unlimited.
