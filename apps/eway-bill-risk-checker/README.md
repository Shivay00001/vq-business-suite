# E-Way Bill Risk Checker — `eway-bill-risk-checker`

Consignment value + distance + transporter-details checklist → required /
not-required / exempt verdict, validity-days calc, and common rejection-risk
checklist. Does NOT generate e-way bills (portal only).

## Statutory basis (verified Sep 2026)
- Sec 68 + Rule 138: mandatory before movement when consignment value > Rs 50,000.
- Rule 138(10) as amended by Notification 94/2020-CT (1-Jan-2021): 1 day per
  200 km regular cargo, 1 day per 20 km ODC; clock starts at Part B.
- Extension within 8h before/after expiry; 360-day total cap.
- Since 1-Jan-2025: only for documents dated within 180 days.
- Penalty: Rs 10,000 or tax evaded, whichever higher (Sec 129).
- Intra-state thresholds vary by state — tool uses the standard Rs 50,000 and
  says so.

## Free limit
20 checks/day (metered).
