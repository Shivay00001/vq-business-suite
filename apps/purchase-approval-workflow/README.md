# Purchase Approval Workflow
Cluster: procurement-vendor (Team I, batch 4).
Slab-based approval matrix (default: ≤25k HOD; ≤1L +Finance; ≤5L +Director; above +MD — editable). Requests flow through the chain in order; out-of-turn actions are refused; every action is recorded in a timestamped audit trail. Up to 25 requests in the on-device vault.
