# Single Point of Failure Detector — `single-point-of-failure-detector`

Track up to 25 key roles / vendors / systems with dependency (1–5) and
backup coverage (none/partial/full). SPOF score = dependency × coverage
gap (none=3, partial=2, full=1); severity Critical/Watch/Covered; ranked
worst-first with remove buttons. Snapshots savable to on-device vault
(max 25).

## Free limits
20 entries/day (metered). Vault snapshots capped at 25.

## Honest limitation
Self-assessment estimate, not an operations audit. Confirm redundancy
plans with your operations head/auditor.
