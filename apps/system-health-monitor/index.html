IT health monitor — FAQs

What does the IT health score measure?

Ten weighted checks — backups (exist, off-site, restore-tested), OS updates, antivirus, disk space, passwords, 2FA, Wi-Fi security and exit revocation — scored 0–100 with an A–F grade.

सिस्टम हेल्थ स्कोर क्या है?

10 जांचों पर आधारित 0–100 स्कोर — बैकअप, अपडेट, एंटीवायरस, डिस्क स्पेस, पासवर्ड, 2FA। फेल जांचों के लिए प्राथमिकता वाली एक्शन लिस्ट मिलती है।

What should I fix first?

The action list is sorted by severity: critical items (like missing backups) first, then high, then medium.

Is this a security audit?

No — it is a self-assessment checklist for small businesses, not a professional security audit.
